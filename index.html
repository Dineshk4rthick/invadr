Platform Architecture

Four tightly integrated layers

1) Field Mobile App

Expo React Native app with role-based access and offline-first report capture: photo, notes/audio, timestamp, and GPS.

  • Capture -> Compress -> Predict -> Local Store -> Sync
  • Sync states: pending, syncing, uploaded
  • Map markers and outbreak overlays for field awareness

2) AI + Backend Intelligence

FastAPI services for auth, report ingestion, model inference, analytics APIs, and role-based admin access.

  • TensorFlow species classification + confidence score
  • Spatial-temporal risk logic for hotspot detection
  • Secure token-based access for users and admins

3) Admin Monitoring Dashboard

Command center for live field intelligence, report triage, and coordinated response planning.

  • Map + feed monitoring in near real time
  • Species distribution and high-risk trend tracking
  • Detailed report inspection for validation workflows

4) Foresight + Resilient Connectivity

Satellite time-series change detection and LoRa edge telemetry support for no-network transmission.

  • Forecast spread risk before broad ground confirmation
  • Fuse predictions with field reports for early warning
  • LoRa relay path from remote zones to gateway nodes
